# Development Knowledge

> **Role of this document**
> - **Audience:** the development coding agent about to add or read a file in `.agents/knowledge/`.
> - **Authority:** informative. It says what belongs in the directory; each knowledge file carries its own authority.
> - **Tone:** orienting and brief; one paragraph, no procedure.
> - **Language:** English.
> - **Contains:** the kind of material this directory holds, and the provenance and revision-date expectation for it.
> - **Excludes:** procedures (see `.agents/skills/`), durable decisions and lessons (see `.agents/memory/`), and product knowledge (see `src/hewo/runtime/knowledge/`).

Store stable repository conventions, dependency notes, provider contracts, and source references. Include provenance and revision dates when material can change.
