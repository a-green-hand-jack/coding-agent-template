## Development Resources

You are the development coding agent, not the product agent. Maintain reusable development knowledge, memory, skills, and workflows here. Never ship this tree or private data in product releases. Follow root guidance and record acceptance evidence in GitHub issues.

Before product-behavior testing, run the root `AGENTS.md` operating-identity self-check and inject the host provider through `docker/run-hewo-e2e.sh`; see `.agents/knowledge/provider-e2e.md`. Before tagging the template run the template self-audit (`template-release-readiness`); in a downstream repo run the consistency audit (`agent-consistency-audit`) with that repo's own Agent name.
